## How to Set Up TiviLive on a MAG Box

The setup is fairly old-school, which is honestly part of the MAG experience.

First, find the MAC address of your MAG box. TiviLive's current guide directs users to **Settings → System Settings → About** and asks them to send the MAC address to support for activation.

Next, open the MAG portal settings:

**Settings → System Settings → Servers → Portals**

Enter **TiviLive** as the portal name and paste the portal URL supplied by support into the Portal 1 URL field. Save the settings and restart the MAG box. According to TiviLive's guide, the channel list should load after the reboot.

TiviLive recommends an internet connection of around 15 Mbps or more for general streaming and 25 Mbps or more for 4K/UHD on its installation page. It also says a wired Ethernet connection is preferred for stability.

That last part matters more than people sometimes expect. If the portal loads but a stream keeps buffering, the IPTV subscription may not be the only suspect. Wi-Fi interference, network congestion and the particular channel source can all affect playback.
